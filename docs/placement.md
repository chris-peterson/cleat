# Placement guide

When a write adds guidance to `AGENTS.md`, `CLAUDE.md`, or a topic rule, cleat
stops it once and asks the agent where the guidance belongs: could a hook decide
it, does every session need it, is it a topic of its own or bound to one
directory. The deny names this guide by its path in the plugin, so the agent
reads it only when the question comes up, and it costs no context otherwise. If
the guidance belongs where it was written, the agent re-issues the identical
write and it goes through.

What follows is the guide as the agent reads it. The reasoning behind its
choices is in [Feedback loops](/feedback-loops).
