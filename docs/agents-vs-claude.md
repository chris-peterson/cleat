# Rubric

When an agent writes a `CLAUDE.md` that carries real guidance into a repo with
no `AGENTS.md`, cleat stops the write and asks for a split: the body goes to
`AGENTS.md`, and `CLAUDE.md` keeps the `@AGENTS.md` pointer plus whatever is
genuinely Claude-specific. The deny carries the rubric's short form and names
this guide by its path in the plugin for the long one. cleat's offers to fix a
repo's shape, made when the agent reads a file that shows the repo is off it,
name the guide too.

What follows is the guide as the agent reads it.
